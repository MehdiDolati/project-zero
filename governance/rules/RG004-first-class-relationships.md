# Statement

Relationships between Artifacts MUST be explicitly represented as first-class elements of the knowledge model.

Relationships are not merely textual references.

---

# Rationale

Knowledge is created by connections between Artifacts.

Explicit relationships enable reasoning, validation, visualization, and traceability.

---

# Consequences

Following this rule:

- improves explainability,
- enables graph-based reasoning,
- supports future automation.

Ignoring this rule reduces the repository to disconnected documents.

---

# Applies To

All Artifact relationships.

---

# Exceptions

None currently defined.
