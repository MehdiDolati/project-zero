# Purpose

Documentation exists to preserve the current understanding of the project.

Documentation is not written to satisfy process.

It is written to reduce future uncertainty.

---

# Core Principle

The repository is the single Source of Truth.

If reality and documentation disagree, one of them is wrong.

The discrepancy must be resolved.

---

# Documentation Lifecycle

Documentation evolves through the following stages:

Draft

↓

Review

↓

Accepted

↓

Superseded

↓

Archived

No document should silently become obsolete.

---

# Artifact Ownership

Every document MUST have:

- an identifier,
- an owner,
- a status,
- a last review date.

Ownership implies responsibility for maintaining accuracy.

---

# Documentation Changes

Documentation MUST be updated whenever one of the following occurs:

- a governance rule changes,
- a research methodology changes,
- a major decision is accepted,
- a foundational hypothesis changes,
- repository structure changes,
- terminology changes.

Minor editorial improvements do not require governance review.

---

# Documentation Quality

Documentation SHOULD:

- be concise,
- explain reasoning,
- avoid duplication,
- reference related artifacts,
- separate facts from assumptions.

---

# Sessions

Research Sessions are snapshots of project evolution.

They are not meeting minutes.

A Session SHOULD record:

- important insights,
- changed beliefs,
- created artifacts,
- significant decisions,
- unresolved questions.

---

# Living Documents

Some documents are expected to evolve continuously.

Examples include:

- North Star
- Research Methodology
- Documentation Governance

These documents SHOULD be periodically reviewed even if no major change occurs.

---

# Deprecation

A document MUST NOT be deleted simply because it is outdated.

Instead it should:

- be marked as superseded,
- reference its replacement,
- remain accessible for historical traceability.

---

# Automation

Documentation quality should first be maintained through disciplined review.

Automation may later assist by identifying:

- missing metadata,
- broken references,
- outdated links,
- missing required artifacts.

Automation supports documentation.

It does not replace human judgment.
