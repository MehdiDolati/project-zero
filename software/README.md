# Software

This directory is intentionally empty.

Project Zero operates as a manual research system
([DEC001](../decisions/DEC001-no-software-before-method.md)). Custom software
is justified only when:

- a manual process exists,
- the process has demonstrated value through repeated execution,
- automation clearly reduces cost or increases quality,
- existing tools cannot reasonably solve the problem.

Until then, existing commercial and open-source tools should be preferred
whenever they sufficiently support the research process
([RG001](../governance/rules/RG001-automation-follows-stability.md)).

The presence of `.gitkeep` in this directory is a placeholder that preserves
the directory structure; it is not an artifact.
