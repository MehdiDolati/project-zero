# Questions

This directory holds structured research questions and observations that are
important enough to persist, but have not yet become hypotheses, evidence, or
project knowledge.

Questions preserve the uncertainty to be reduced. They do not assert that a
market behavior exists, that an explanation is correct, or that a strategy is
profitable.

## Identity and Location

Question artifacts use the stable identity family `Q` and the filename form:

```text
questions/QNNN-<kebab-case-title>.md
```

For example: `questions/Q001-conditional-mean-reversion-aud-crosses.md`.

## Lifecycle

A question starts as `draft`. It is ready for review only when its raw input,
evidence status, assumptions, unknowns, scope, and independent questions are
explicit. A reviewed question may motivate one or more hypotheses; it does not
become evidence simply by being accepted.

Use [the Question / Observation template](../governance/templates/question-observation.md)
to create a new question artifact.
