# Project Zero — Daily Routine

## Purpose

This routine converts Project Zero from an intention into a repeatable daily behavior.

The routine should be lightweight.

It must never become another project.

---

# Daily Start

When beginning a Project Zero work session:

### 1. Reconnect

Open the repository.

Read only the minimum context required:

* current project direction
* latest relevant session
* current `NEXT ACTION`

Do not reread the entire project.

---

### 2. Find the Next Action

Ask:

> What is the concrete thing I already decided to do next?

If a clear `NEXT ACTION` exists:

**Do it.**

If it does not exist:

Spend the minimum necessary time defining one.

Do not turn this into a planning session.

---

### 3. Close the Doors

Before starting focused work:

* close unrelated applications
* close unrelated browser tabs
* silence unnecessary notifications
* do not open the Parking Lot
* do not browse for unrelated ideas

The objective is to reduce opportunities for context switching.

---

### 4. Start One Focus Session

Choose an appropriate duration:

* 25 minutes on a difficult day
* 45–60 minutes normally
* longer when naturally productive

During the session:

> One task. One direction.

If another idea appears:

```text
CAPTURE → PARK → RETURN
```

---

# During the Session

Do not ask:

> What else could I improve?

Ask:

> What evidence or artifact am I trying to produce right now?

Keep moving toward the defined outcome.

---

# Daily Shutdown

Before closing Project Zero:

### DONE

Record what was completed.

### LEARNED

Record important observations or discoveries.

### NEXT

Write exactly one concrete next action.

Example:

```text
DONE:
- Implemented the first robustness calculation.

LEARNED:
- Trade count needs to be considered alongside profitability.

NEXT:
- Define the minimum trade-count threshold.
```

The next action should be executable without another planning session.

---

# Bad-Day Protocol

If energy, time, or motivation is low:

Do not abandon the project.

Switch to Minimum Viable Progress.

Choose one:

* 20 minutes of focused work
* one small implementation
* one experiment
* one documented observation
* one decision
* one cleanup that directly enables the next step

Then perform the shutdown ritual.

A small completed session is better than losing the thread entirely.

---

# Weekly Review

Once per week:

```text
DONE
LEARNED
DISTRACTIONS
KEEP
CHANGE
DELETE
NEXT
```

Use this review to reconsider priorities.

Do not continuously redesign the project during daily work.

---

# Rules

## Rule 1

There is one primary Project Zero direction.

## Rule 2

Every session starts with a concrete NEXT ACTION.

## Rule 3

New ideas go to the Parking Lot first.

## Rule 4

Do not change direction merely because the current task becomes difficult.

## Rule 5

Do not confuse more research with more progress.

## Rule 6

A rejected hypothesis is legitimate progress.

## Rule 7

Never finish a meaningful session without defining the next action.

## Rule 8

The system exists to reduce friction, not create bureaucracy.

---

# The 60-Second Version

When opening the computer:

```text
[ ] Open Project Zero
[ ] Read latest session
[ ] Find NEXT ACTION
[ ] Ignore Parking Lot
[ ] Start focus session
```

When closing:

```text
[ ] DONE
[ ] LEARNED
[ ] NEXT
```

That's it.

---

# Core Reminder

> **Don't decide what to work on every day. Decide once, then continue.**

> **The goal is not to work hard every day. The goal is to keep Project Zero moving.**
